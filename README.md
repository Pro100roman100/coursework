<H1>Структура проєкту</H1>

Всі класи мають відповідні .h файли, і всі, окрім інтерфейсів, мають .сpp   *(player.h, player.cpp і тд)*

У папці GFX зберігаються вся графіка для гри.

У data.txt зберігається складність та пройдені карти, у map.txt map1.txt ... зберігається інформація про об'єкти на карті




<H2>Основні класи</H2>

class Game:
- Відповідає за керування ігровою логікою
- Містить GameState що керує поточним станом (меню, гра, вибір рівня, налаштування, кінець гри)
  - Кожен стан відповідає за інтерфейс та процес переходу між станами.

class UiManager:
- Відповідає за керування інтерфейсом
- UiElement являється батьківським класом для всіх об'єктів інтерейсу (текст, кнопка тд) і використовується UiManager-ом

class ObjectManager:
- Відповідає за створення, оновлення, відображення та видадення Об'єктів гри
- GameObject являється батьківським класом для всіх об'єктів у грі і використовується ObjectManager-ом

class PhysicsManager:
- Відповідає за фізичні взаємодії між об'єктами
- PhysicsObject являється батьківським класом для всіх фізичних об'єктів у грі і використовується PhysicsManager-ом
- PhysicsObject автоматично додається до списку об'єктів при створені і видаляється при видалені

class Character:
- Являється дочірім для ворога і гравця
- Має InventoryManager що зберігає зброю і снаряди до Character
  - Містить масив Weapon, що є дочірнім для всіх видів збої

class Item: 
- Являється дочірім для всіх предметів у грі
